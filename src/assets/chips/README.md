# Official Snapdragon badge artwork (optional)

Drop Qualcomm's official chip badge images here and the app will use them
automatically instead of the built-in stylized badges. Requires permission
from Qualcomm's brand/trademark guidelines to distribute.

Expected filenames (png, webp, or svg):

- `x.png` — Snapdragon X
- `x-plus.png` — Snapdragon X Plus
- `x-elite.png` — Snapdragon X Elite
- `x2-plus.png` — Snapdragon X2 Plus
- `x2-elite.png` — Snapdragon X2 Elite

Square images work best (they render at 18–24 px).
